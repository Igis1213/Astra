# Astra

S&P500 퀀트 전략의 **실운용 성과** 대시보드 → https://igis1213.github.io/Astra/

GCP 서버가 매 세션 마감 후 `data/*.json` 을 갱신해 push하고, 이 페이지가 그걸 읽어 그린다.

## 이 저장소에 없는 것

전략 로직·백테스트 엔진·주문 집행 코드는 여기 없다(비공개 저장소에 있다).
여기 있는 것은 정적 페이지와 그 페이지가 읽는 성과 데이터뿐이다.

## 데이터에 금액이 없는 이유

수익률을 보이는 게 목적이지 계좌 잔고를 공개하는 게 목적이 아니다. 내보내기 단계에서
아예 빼기 때문에 페이지 소스를 뜯어도 금액은 나오지 않는다.

| 필드 | 내보냄 |
|---|---|
| 총자산 | 시작=100 **지수**로 정규화 |
| 수익률·비중·기여도 | % |
| 종목·섹터·진입일·체결가 | 그대로 (공개 시장 정보) |
| 수량·평가금액·수수료·실현손익 | **제외** |

## 지표에 대한 단서

- **연평균 수익률은 CAGR이다** — IRR이 아니다. 입출금 시점별 현금흐름 기록이 없어
  IRR은 계산할 수 없다.
- 진입일·평단은 체결 이력을 FIFO로 되감아 복원한 값이다.
- challenger(shadow) 주문은 집행하지 않은 주문이라 성과에서 전부 제외된다.
